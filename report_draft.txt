ABSTRACT
----------------------------------------------------------------
We present StockSync, a real-time automated retail inventory
tracking system deployed on the NVIDIA Jetson Orin Nano. The
system uses a fine-tuned YOLOv8n instance segmentation model to
detect and count shelf items from a live camera feed. We
collected and labeled a custom dataset of 425 images across five
product classes (chocolate, granola, mouse, pen, waterbottle)
using Roboflow. The model was trained on Google Colab with GPU
acceleration and optimized using NVIDIA TensorRT for edge
deployment. Our final model achieves a mask mAP@50 of 88.7% on
the held-out test set, with near-perfect performance on
waterbottle (98.5%) and granola (99.2%). The system outputs
real-time per-class inventory counts to a live dashboard,
enabling automated shelf monitoring without manual inspection.


----------------------------------------------------------------
1. INTRODUCTION
----------------------------------------------------------------
Retail inventory management is a labor-intensive process.
Employees must periodically walk store aisles to manually count
shelf stock, a process that is time-consuming, error-prone, and
does not scale to large stores. Out-of-stock events cost
retailers an estimated $1 trillion annually in lost sales
globally [CITE]. Automating inventory tracking through computer
vision offers a practical solution: a camera mounted above a
shelf can continuously monitor stock levels and alert staff when
items run low.

We develop StockSync, a shelf inventory tracking system that
runs on the NVIDIA Jetson Orin Nano developer kit — an
affordable, low-power edge AI platform. Our system detects and
segments individual retail items in real time using a custom-
trained YOLOv8n-seg model, counts per-class instances per frame,
and displays live inventory counts on a web dashboard.

The key contributions of this project are:
  (1) A custom dataset of 425 shelf images across 5 product
      classes, collected with real cameras and labeled with
      instance segmentation masks.
  (2) A fine-tuned YOLOv8n-seg model achieving 88.7% mask
      mAP@50 on unseen test data.
  (3) A TensorRT-optimized inference pipeline deployed on the
      NVIDIA Jetson Orin Nano for real-time edge inference.
  (4) A full-stack dashboard displaying live per-class inventory
      counts from the camera feed.


----------------------------------------------------------------
2. RELATED WORK
----------------------------------------------------------------

Object Detection on Edge Devices.
YOLO (You Only Look Once) [Redmon et al., 2016] introduced
single-stage real-time object detection. YOLOv8 [Ultralytics,
2023] extends this with an anchor-free architecture and native
support for instance segmentation, making it well-suited for
edge deployment. Prior work has deployed YOLO variants on
Jetson platforms for traffic monitoring [CITE] and industrial
inspection [CITE].

Retail Inventory Tracking.
Vision-based shelf monitoring has been explored using classical
computer vision [CITE] and deep learning [CITE]. Recent systems
use object detection to count items and detect gaps on shelves
[CITE]. Our work differs in targeting edge deployment on low-
cost hardware with a fully custom dataset.

Instance Segmentation.
Mask R-CNN [He et al., 2017] introduced the standard two-stage
approach to instance segmentation. YOLOv8-seg adapts this to a
single-stage real-time framework using a lightweight mask head,
enabling deployment on constrained hardware like the Jetson
Orin Nano.

TensorRT Optimization.
NVIDIA TensorRT [NVIDIA, 2023] optimizes deep learning models
for inference on NVIDIA GPUs through layer fusion, precision
calibration (FP16/INT8), and kernel auto-tuning. Prior work
demonstrates 2-5x speedup on Jetson platforms compared to
standard PyTorch inference [CITE].

3.2 Dataset
We collected 425 images using a Logitech C270 HD Webcam and an
8MP IMX219 camera across five product classes: chocolate,
granola, mouse, pen, and waterbottle. Images were captured under
varying lighting conditions and shelf arrangements to improve
generalization. Annotation was performed using Roboflow with
instance segmentation (polygon) masks.

The dataset was split into train/val/test as follows:

  Class          Train   Val   Test   Total
  -----------------------------------------
  waterbottle      113    29     23     165
  granola           87    15     12     114
  chocolate         68    21     16     105
  pen               33     8      9      50
  mouse             18     2      2      22
  -----------------------------------------
  Total            319    75     62     456 images
                   293    72     60     425 (unique)

3.3 Model: YOLOv8n-seg
We selected YOLOv8n-seg (nano segmentation variant) for its
balance of accuracy and inference speed. The model uses a CSP
(Cross Stage Partial) backbone, PANet neck, and a lightweight
segmentation head that predicts both bounding boxes and polygon
masks. With 3.26M parameters and 11.5 GFLOPs, it is well-suited
for real-time inference on the Jetson Orin Nano.

We initialized from ImageNet-pretrained weights (yolov8n-seg.pt)
and fine-tuned on our custom dataset, overriding the output head
for nc=5 classes.

3.4 Training
Training was performed on Google Colab with an NVIDIA Tesla T4
GPU (16GB). Hyperparameters:

  - Epochs:     100 (early stopped at epoch 65, patience=15)
  - Batch size: 8
  - Image size: 640x640
  - Optimizer:  AdamW (lr=0.001111, momentum=0.9)
  - Augmentation: random flip, HSV jitter, mosaic, erasing,
                  blur, CLAHE

Training completed in approximately 10 minutes. The best
checkpoint (highest val mAP@50) was saved at epoch 50.

Figure 1 shows the training and validation loss curves across
epochs. All losses (box, segmentation, classification) decrease
steadily, confirming stable convergence. Figure 2 shows mAP@50
and mAP@50-95 improving rapidly in the first 30 epochs and
plateauing around epoch 50, after which early stopping triggered
at epoch 65 with no further improvement.

3.5 TensorRT Optimization
The trained best.pt PyTorch model was exported to TensorRT
engine format on the Jetson Orin Nano using the Ultralytics
export pipeline with FP16 precision. TensorRT performs layer
fusion and kernel auto-tuning for the Jetson's CUDA cores,
resulting in significantly faster inference compared to standard
PyTorch.

3.6 Deployment
The TensorRT-optimized model runs on the Jetson Orin Nano
connected to the IMX219 camera. The inference pipeline
(inference.py) captures frames, runs detection, and counts per-
class instances. Results are sent to a backend server (Hassan)

4.1 Evaluation Metrics
We evaluate using standard COCO metrics:
  - mAP@50:    mean Average Precision at IoU threshold 0.50
  - mAP@50-95: mean AP averaged over IoU thresholds 0.50-0.95
  - Precision and Recall at the default confidence threshold

We report both box (detection) and mask (segmentation) metrics.
Final evaluation is on the held-out test set (60 images, 178
instances) not seen during training or validation.

4.4 Analysis
The model performs strongly on well-represented classes.
Waterbottle (165 training images) and granola (114 images)
achieve near-perfect segmentation. Pen is the weakest class
(0.601 mAP@50) due to limited training data (only 33 training
images) and the inherent difficulty of segmenting thin, small
objects. Mouse achieves high mAP@50 (0.995) but was evaluated
on only 2 test images, so this score may not generalize.

The drop from val (0.944) to test (0.887) is expected and
indicates modest overfitting, likely due to the small dataset
size. Additional data collection for pen and mouse is the
primary avenue for improvement.

----------------------------------------------------------------
5. CONCLUSION
----------------------------------------------------------------
We presented StockSync, a real-time retail shelf inventory
tracking system running on the NVIDIA Jetson Orin Nano. By
fine-tuning YOLOv8n-seg on a custom 425-image dataset, we
achieved 88.7% mask mAP@50 on unseen test data. Three of five
classes exceed 98% mAP@50, demonstrating the viability of
edge-deployed instance segmentation for retail monitoring.

Classes with fewer training images (pen: 33, mouse: 18) showed lower       
performance, suggesting data collection is the primary bottleneck for 
improvement. Future work should collect 80-100
additional images per class and retrain. The full pipeline —
data collection, labeling, training, TensorRT optimization, and
edge deployment with live dashboard — demonstrates a complete
end-to-end computer vision system suitable for real-world retail
applications.
